# Jungle Runner — Endless Survival

A lightweight, browser-based 3-lane endless runner game set in a jungle environment. Run as far as you can, collect coins, and avoid obstacles!

## Features

- Three-lane endless runner gameplay
- Jungle-themed environment
- Collectible coins and score tracking
- Obstacles: rocks, fallen logs, and crates
- Jump, slide, and lane-switch controls
- Health, stamina, and zombie-threat indicators
- Pause and restart options
- Keyboard and mobile touch controls
- No external assets or libraries required

## How to Play

### Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Select **START RUN**.

### Controls

| Action | Keyboard | Mobile |
|---|---|---|
| Move left | `←` or `A` | Left button |
| Move right | `→` or `D` | Right button |
| Jump | `↑`, `W`, or `Space` | JUMP button |
| Slide | `↓` or `S` | SLIDE button |
| Pause / Resume | `P` or pause button | Pause button |

## Scoring

- Travel farther to increase your distance score.
- Collect gold coins to earn bonus points.
- Avoid obstacles to preserve your health.
- The run ends when your health reaches zero.

## Deploy with GitHub Pages

1. Push `index.html` and this `README.md` to the root of your GitHub repository.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. After GitHub Pages finishes deploying, open the URL shown in the Pages settings.
